# PRAGATI MOTORS - Tractor Selling Website

A modern, responsive website for PRAGATI MOTORS, a tractor selling firm. This website showcases the company's products, services, and provides an easy way for customers to get in touch.

## Features

### 🚜 **Modern Design**
- Clean, professional layout with agricultural theme
- Responsive design that works on all devices
- Smooth animations and hover effects
- Modern color scheme with green and gold accents

### 📱 **Responsive Layout**
- Mobile-first design approach
- Hamburger menu for mobile navigation
- Optimized for tablets, phones, and desktops
- Touch-friendly interface elements

### 🎯 **Key Sections**
- **Hero Section**: Compelling call-to-action with company branding
- **Products**: Showcase of different tractor categories (Compact, Utility, Heavy-Duty)
- **Services**: After-sales support, delivery, training, and financing
- **About Us**: Company information with statistics and achievements
- **Contact**: Contact form and business information

### ⚡ **Interactive Features**
- Smooth scrolling navigation
- Mobile hamburger menu
- Form validation and submission handling
- Animated counters for statistics
- Parallax effects
- Notification system
- Hover animations and transitions

### 🛠 **Technical Features**
- Pure HTML5, CSS3, and JavaScript (no frameworks)
- Font Awesome icons for visual elements
- Google Fonts (Poppins) for typography
- CSS Grid and Flexbox for layout
- Intersection Observer API for animations
- Accessibility features (ARIA labels, keyboard navigation)

## Getting Started

1. **Clone or Download** the files to your local machine
2. **Open** `index.html` in your web browser
3. **Customize** the content, colors, and images as needed

## Customization

### Colors
The website uses a green and gold color scheme that can be easily customized in `styles.css`:
- Primary Green: `#2c5530`
- Secondary Green: `#4a7c59`
- Accent Gold: `#ffd700`

### Content
- Update company information in the HTML file
- Modify product details and descriptions
- Change contact information and business hours
- Add real tractor images to replace the placeholder icons

### Images
To add real tractor images:
1. Replace the tractor icon placeholders with actual images
2. Update the CSS to use `background-image` instead of Font Awesome icons
3. Ensure images are optimized for web (WebP format recommended)
